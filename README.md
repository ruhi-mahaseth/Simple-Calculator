# 🧮 Simple Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic mathematical operations.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Power (^)
- Percentage (%)
- Parentheses ( )
- Clear button (AC)
- Calculation using (=)
- Simple and user-friendly interface
- Interactive buttons
- Displays calculation results

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Calculator functionality and calculations
